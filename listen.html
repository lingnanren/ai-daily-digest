15. 软弃用 re.match()

Soft-deprecating re.match() — simonwillison.net · 13 小时前 · ⭐ 24/30

中文摘要

Python 3.15 版本将对 re.match() 函数进行“软弃用”。软弃用意味着该 API 不再推荐用于编写新代码，但不会立即移除，也不会有强制移除的承诺。这种做法旨在引导开发者逐步迁移到更推荐的替代方案，同时避免破坏现有代码的兼容性。这是 Python 社区管理 API 演进的一种策略。

English Summary

The upcoming Python 3.15 release will implement a 'soft deprecation' for the re.match() function. Soft deprecation signifies that the API is no longer recommended for new code but will not be immediately removed or have a guaranteed removal date. This approach aims to guide developers towards preferred alternatives without breaking existing code compatibility, representing a strategy for managing API evolution within the Python community.

🏷️ Python, re.match, deprecation
