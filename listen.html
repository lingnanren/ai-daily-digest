🥇 从专有 LLM API 中窃取推理轨迹

Stealing Reasoning Traces from Proprietary LLM APIs — simonwillison.net · 3 小时前 · 🤖 AI / ML

中文摘要

一项新研究发现，Anthropic、OpenAI 和 Google 等公司的专有大型语言模型（LLM）API 会向客户端返回加密的“思维链”（chain-of-thought）数据块。这些数据块可以在不同会话、用户和模型之间重放。研究人员成功地从一个前沿模型捕获推理轨迹，并在一个较弱的同类模型上重放，从而绕过了安全限制，揭示了模型内部的推理过程。

English Summary

A new paper reveals that proprietary LLM APIs from companies like Anthropic, OpenAI, and Google return encrypted chain-of-thought (CoT) blocks to clients. These CoT traces can be replayed across sessions, users, and models. Researchers successfully captured a reasoning trace from a frontier model and replayed it into a weaker sibling model, bypassing security measures and exposing the model's internal reasoning process.

💡 为什么值得读: 揭示了大型语言模型 API 的一个潜在安全漏洞，允许通过重放推理轨迹来提取内部工作机制。

💡 Why read it: Reveals a potential security vulnerability in large language model APIs, allowing the extraction of internal workings by replaying reasoning traces.

🏷️ LLM, reasoning traces, proprietary APIs
