English Summary

The Windows Update hot patcher checks if a target function has already been patched before installation. If the function is already patched, the hot patch will not be installed again. This prevents the same patch from being applied multiple times, avoiding potential conflicts or inconsistencies. However, this does not prevent the installation of multiple different hot patches, as long as they modify different functions or modify them in a compatible manner.
