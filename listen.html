7. C++ 提醒：函数局部静态变量仅初始化一次

中文摘要

本文提醒 C++ 开发者，函数内部的静态变量（static variables）仅会在函数首次执行时进行初始化，即使在代码中看起来像是被初始化了多次。这一特性确保了静态变量的全局唯一性和生命周期。

English Summary

This post serves as a reminder for C++ developers that function-local static variables are initialized only once, specifically upon the first execution of the function, regardless of how many times the initialization code appears to be encountered. This ensures the uniqueness and lifecycle of static variables.
