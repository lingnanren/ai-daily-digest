To re-enable the logo illumination, the command sudo defaults delete com.apple.CoreBrightness LEBacklightMo should be used.

2. 不应在创建后更改 Win32 静态控件的样式

Why are we all worked up about atomicity when applying hot-patches if we can just suspend all the threads? — devblogs.microsoft.com/oldnewthing · 14 小时前 · ⭐ 25/30

中文摘要

在 Windows 开发中，不建议在创建 Win32 静态控件（Static Control）后更改其样式。这是因为控件的设计并未充分考虑这种动态样式修改的场景，可能导致不可预测的行为或渲染问题。开发者应在控件创建时就确定其样式。

English Summary

In Win32 development, it is inadvisable to change the style of a static control after it has been created. The control is not designed to handle such dynamic style modifications effectively, which can lead to unpredictable behavior or rendering issues. Developers should set the desired style at the time of creation.
