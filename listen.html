中文摘要

在使用 Ubuntu 26.04 时，Ansible 自动化在配置 sudo 需要密码时会遇到特权升级失败的问题。作者发现，当 sudo 配置为要求输入密码时，Ansible 的 become 命令会卡住，提示 'sudo: a password is required'。通过修改 /etc/sudoers 文件，禁用 requiretty 选项并允许 Ansible 用户无需密码执行 sudo 命令，可以解决此问题，从而恢复 Ansible 的正常自动化部署。

Ansible automation fails on Ubuntu 26.04 when sudo requires a password for privilege escalation. This issue can be resolved by modifying the /etc/sudoers file to disable the requiretty option and allow the Ansible user to execute sudo commands without a password, restoring normal automation.
