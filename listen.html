7. Datasette 插件 datasette-leaflet 更新至 0.3 版本

This Week in Package Management: 14 November 2026 — nesbitt.io · 19 小时前 · ⭐ 25/30

中文摘要

Datasette 的 datasette-leaflet 插件已更新至 0.3 版本。OpenStreetMap 要求其托管的图块服务器请求应包含 referrer 头信息。之前的 Datasette 版本使用了 'Referrer-Policy: no-referrer' HTTP 头，导致加载 OpenStreetMap 图块的插件违反了这一策略。新版本解决了这个问题，确保了对 OpenStreetMap 政策的合规性。

English Summary

The datasette-leaflet plugin for Datasette has been updated to version 0.3. OpenStreetMap requires that requests to its hosted tile server include a referrer header. Previous Datasette versions used the 'Referrer-Policy: no-referrer' HTTP header, causing plugins loading OpenStreetMap tiles to violate this policy. The new version resolves this issue, ensuring compliance with OpenStreetMap's policy.
