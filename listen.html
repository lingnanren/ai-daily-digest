Microsoft Plugs Nearly 1,000 Security Holes — krebsonsecurity.com · 6 小时前 · 🔒 安全

中文摘要

Linux 内核官方 Git 仓库 git.kernel.org 正面临日益严重的恶意爬虫问题。这些爬虫消耗的 CPU 资源已超过所有合法访问（包括 Git 克隆）的总和。作者指出，渲染提交信息给爬虫所花费的 CPU 周期，比服务所有其他合法用户（如克隆仓库）的资源还要多。这种“背景辐射”式的滥用正严重影响仓库的正常运行和资源分配。

English Summary

The official Git repository for the Linux kernel, git.kernel.org, is experiencing a significant problem with abusive crawlers. These bots are consuming more CPU cycles rendering commits for scrapers than for all legitimate access, including Git clones. The "background radiation" of these crawlers is so severe that it outweighs the resources used for all other valid operations, impacting the repository's performance and resource allocation.
